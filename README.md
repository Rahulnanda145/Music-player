# YouTube Music Clone & Playlist Importer

A web-based music streaming player inspired by YouTube Music with playlist import support.

## Features
- Search tracks and artists via `/api/search`
- Retrieve song metadata via `/api/song/:videoId`
- Embedded continuous playback using YouTube IFrame API
- Dark-themed responsive interface
